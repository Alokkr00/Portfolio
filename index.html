Financial Fraud Analytics
Python Pandas Forensic EDA Matplotlib

Credit Card Fraud Forensic Analysis

PaySim 6M+ Transactions 0.13% Imbalanced EDA Cost-Sensitive ML Design
Data Pipeline: PaySim Log (6.3M rows) → Pandas Ingestion → Behavioral Subsetting (TRANSFER/CASH_OUT) → Mule Flow Profiling → PR-AUC Evaluation Design

Forensic exploratory data analysis of the PaySim synthetic mobile-money transaction log, investigating fraud in a highly imbalanced environment (about 0.13% fraud). Findings: 100% of fraudulent transactions occurred only via TRANSFER and CASH_OUT; fraudulent transfers typically drained the origin account to zero; fraud ran through mule accounts (TRANSFER in, immediate CASH_OUT); the dataset's static rule flag (amounts over 200,000) had near-zero recall. Recommended a cost-sensitive gradient boosting architecture evaluated on PR-AUC, not raw accuracy. EDA and recommendations only; no production model was trained or deployed.
